# Smoke Zone & BUDDY BIN Initiative Website

A production-ready, single-page web presentation for **Shravni's Hospitality - Smoke Zone & BUDDY BIN Circular Recycling Initiative**.

## 🚀 How to Install and Run

### Prerequisites
- Node.js (v18 or higher recommended)
- NPM (v9 or higher)

### 1. Installation
```bash
npm install
```

### 2. Development Mode
Start the Vite development server:
```bash
npm run dev
```
Open your browser at `http://localhost:3000`.

### 3. Production Build
To create an optimized production bundle:
```bash
npm run build
```

### 4. Preview Production Build
```bash
npm run preview
```

## 📐 Implemented Sections

1. **Header & Navigation:** Sticky glassmorphic header with wordmark, anchor links, direct phone link, and an accessible mobile hamburger drawer.
2. **Hero Section:** Architectural headline, tagline, live badges (99.95% HEPA H13, 18+ Branches, ASHRAE Compliant), CTA buttons, and a featured canopy installation photo.
3. **Project Overview (About):** Detailed breakdown of corporate smoking challenges vs. the turnkey Smoke Zone solution, operating hubs across Pune, Mumbai, Bangalore, and Hyderabad.
4. **Air Purification (Filtration System):** Interactive 3-stage filtration breakdown (G3 Pre-Filter, HEPA H13 micro-particulate, Activated Coconut Carbon gas/odor adsorption) with negative pressure flow diagrams.
5. **BUDDY BIN Circular Economy Process:** 6-step waste collection, scheduled handling, item-wise fractioning, washing, and repurposing into craft cellulose fibers, organic fertilizer, and isolated liquid streams.
6. **Cabin Variants:** Architectural configurations covering Indoor Rooms/Lounges, Modular Portable Cabins, Designated Outdoor Smoking Areas (DOSAs), and Executive Cigar Lounges.
7. **Site Installations & Gallery:** Curated grid of authentic site photography with full-screen lightbox image viewer and embedded video demonstration modal.
8. **Corporate Clients:** Verified client deployment showcase (Mastercard, Godrej, Brookfield, Panchshil, Abacus IT Park, R City Mall, Indialand, etc.).
9. **Technical Specifications:** "At a Glance" engineering specification matrix.
10. **Direct Contact & Proposal Request:** Direct lines (+91 9665 339 076), email (`Director@shravnis.com`), office address in Bavdhan Bk, Pune, and an interactive proposal request modal.
11. **Footer:** Minimalist footer with standard navigation, compliance notes, and back-to-top scroll controls.
